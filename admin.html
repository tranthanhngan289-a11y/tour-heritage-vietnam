Sao Lưu Dữ Liệu Firebase Cloud

Đồng bộ Booking & Sub-Admin lên Google Firebase

Chế độ Offline (LocalStorage)
Dữ liệu đang lưu trên trình duyệt này. Nhập config để backup lên đám mây.
Thông Số Kết Nối Firebase (Tùy Chọn): Realtime Database
Hướng dẫn 3 phút tạo Firebase miễn phí:
  1. Truy cập console.firebase.google.com và tạo Project mới.
  2. Vào mục Realtime Database → bấm Create Database → chọn chế độ Start in test mode.
  3. Vào Project Settings (biểu tượng bánh răng) → copy apiKey, databaseURL, projectId dán vào ô trên!
